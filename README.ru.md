# LidSwitch

[English](README.md) · **Русский**

LidSwitch — небольшое нативное приложение для menu bar macOS. Оно управляет
тем, продолжит ли работающий MacBook выполнять задачи после закрытия крышки или
перейдёт в сон.

Сайт: [pismenny.ru/lidswitch](https://pismenny.ru/lidswitch/)

Левый клик по единственной иконке сразу переключает режим:

- зелёный экран с числом — Mac продолжит работать с закрытой крышкой, а число
  показывает примерный запас работы от батареи в часах;
- жёлтый экран с `Zz` — при закрытии крышки Mac сможет перейти в обычный сон;
- серый экран с `?` — macOS не сообщила текущее состояние настройки.

После переключения появляется короткое подтверждение. Правый клик открывает
меню с текущим состоянием, прогнозом, обновлением и управлением helper.

В меню также доступны три режима энергии macOS: энергосбережение,
автоматический и высокая производительность. Галочка показывает активный режим.
Выбор применяется одновременно для батареи и адаптера питания.

Прогноз активной работы с закрытой крышкой показывается и на батарее, и при
подключённом питании. На адаптере LidSwitch использует последний расход,
изученный на батарее для выбранного режима энергии. Пока истории нет,
применяется базовая модель.

## Требования

- MacBook с Apple silicon;
- macOS Sequoia 15 или новее.

## Установка

### Homebrew

```sh
brew install --cask dapi/tap/lidswitch
open /Applications/LidSwitch.app
```

Для последующего обновления:

```sh
brew upgrade --cask lidswitch
```

### Готовое приложение

1. Скачайте `LidSwitch-0.7.0-macos-arm64.zip` из
   [последнего релиза](https://github.com/dapi/LidSwitch/releases/latest).
2. Распакуйте архив и перенесите `LidSwitch.app` в `/Applications`.
3. Нажмите на приложение в Finder с зажатым Control, выберите **Открыть**, затем
   ещё раз подтвердите **Открыть**.

Первая публичная сборка подписана ad-hoc и пока не notarized сертификатом Apple
Developer ID. Если после открытия через контекстное меню macOS продолжает
блокировать приложение, один раз снимите quarantine и запустите его снова:

```sh
xattr -dr com.apple.quarantine /Applications/LidSwitch.app
open /Applications/LidSwitch.app
```

Для проверки целостности рядом с архивом в GitHub Release опубликован файл
`.sha256`.

### Сборка из исходного кода

Полный Xcode не требуется — достаточно Swift toolchain из Xcode Command Line
Tools.

```sh
git clone https://github.com/dapi/LidSwitch.git
cd LidSwitch
./Scripts/build-app.sh
mkdir -p ~/Applications
cp -R dist/LidSwitch.app ~/Applications/
open ~/Applications/LidSwitch.app
```

Во время первой настройки macOS один раз попросит подтвердить установку узкого
привилегированного helper через системный интерфейс авторизации. При доступности
можно использовать Touch ID, пароль администратора остаётся запасным вариантом.
Последующие переключения не требуют подтверждения. Устаревший helper
обнаруживается и заменяется во время этой одноразовой настройки.

Установленный helper принадлежит `root` и принимает только фиксированный список
операций: проверка версии, изменение поведения при закрытии крышки и выбор
одного из трёх режимов энергии. Приложение не может передавать ему произвольные
shell-команды или настройки питания. Чтобы удалить helper и разрешение, откройте
меню правым кликом и выберите **Remove passwordless switching…**.

> [!WARNING]
> Работа с закрытой крышкой расходует батарею и выделяет тепло. Не кладите
> работающий MacBook в рюкзак, чехол или другое замкнутое пространство. Сначала
> переключите LidSwitch в жёлтое состояние `Zz`.

## Как это работает

Helper изменяет системный параметр `disablesleep` через `pmset`. Приложение
читает получившееся значение `SleepDisabled` напрямую из `IOPMrootDomain`,
поэтому цвет и меню отражают реальное состояние macOS, а не отдельно
сохранённую догадку.

Прогноз использует скользящую медиану фактического энергопотребления. При
открытой крышке LidSwitch моделирует работу без встроенного дисплея, вычитая его
примерное потребление с учётом яркости. Если Mac уже работает с закрытой
крышкой, используется непосредственно измеренный расход. Прогноз предполагает,
что нагрузка останется похожей, поэтому он меняется вслед за активностью CPU и
GPU.

При питании от сети батарея не сообщает скорость разряда. LidSwitch сохраняет
последнее потребление, изученное на батарее, отдельно для каждого режима
энергии. До первого измерения используются базовые значения: 6 Вт для
энергосбережения, 8 Вт для автоматического режима и 12 Вт для высокой
производительности.

Во время одноразовой настройки helper устанавливается по адресу
`/Library/PrivilegedHelperTools/me.dapi.LidSwitch.Helper`, а узкое правило
проверяется в `/etc/sudoers.d/lidswitch`. Оно разрешает только текущей учётной
записи запускать принадлежащий `root` helper без повторного запроса пароля.
